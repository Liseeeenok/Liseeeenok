Datable

Laravel Vue.js PostgreSQL MySQL 6 months

A platform that brings several databases into one interface: structure, data, analytics and a map of geodata.

Problem

Company databases live in different systems. One interface is needed to inspect structure, browse data, run analytics and show objects on a map.

My role

Project lead and backend developer: architecture, remote database connections, access control, API.

What I built
  • Connections to remote PostgreSQL and MySQL databases with structure scanning.
  • Browsing and editing tables and fields, configuring field types.
  • Access levels and roles: owner, editor, reader.
  • A public API with full documentation for working with database data.
  • A geodata layer: objects on the map and GeoJSON upload.
How it works

Laravel backend with Eloquent models and Bearer-token auth (Sanctum). Remote database structure is synced in the background through queues. The frontend is Vue.js, the map is MapLibre.

Outcome

Work in progress: remote connections, roles and access levels already run on a real institute database (83 tables, 668 fields).
