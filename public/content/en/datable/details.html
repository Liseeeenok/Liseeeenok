Datable

Laravel Vue.js PostgreSQL MySQL 6 months

A platform that brings several databases into one interface: structure, data, analytics and a map of geodata. I led the project and wrote the backend — from the data model to remote database connections.

The task

Company databases are scattered across systems and teams: seeing the structure needs server access, counting figures means exporting to Excel. One tool was needed where structure, data, relations between tables and the geography of objects are visible together.

My role

Project lead and backend developer: designed the model, built remote database connections, access control and the API. The frontend was built with the team.

What I built
  • Connections to remote PostgreSQL and MySQL: reading structure, tables and fields.
  • Browsing and editing tables and fields, configuring field types for the data.
  • Access levels and roles: owner, editor, reader — per database and per table.
  • Background synchronisation of remote structures without blocking the interface.
  • A documented public API so other systems can pull the data.
  • A geodata layer: objects on a map, GeoJSON upload, binding to tables.
How it works

Laravel backend with Eloquent and Bearer-token auth via Sanctum. Remote structures sync through queues so heavy reads never hang a request. The frontend is Vue.js, the map is MapLibre.

Outcome

The platform runs on a real institute database — 83 tables and 668 fields: structure and data are visible without server access, and permissions are enforced.
