An app that turns a thought — spoken or typed — into notes, tasks, subtasks, calendar events and reminders.

Problem

Ordinary task trackers make you fill in fields: project, due date, priority. A thought caught on the move therefore never becomes a structured task.

My role

Sole developer: product, backend, web client, mobile app, speech recognition, integrations and deployment.

What I built
  • Voice or text input parsed automatically into entities: notes, tasks, subtasks, events and reminders.
  • Links between notes, tags, projects, participants and access levels from private to shared.
  • A calendar with month, week, day and list views; a task with a due date gets its event automatically.
  • Recurring tasks and reminders, plus a recycle bin with restore.
  • An in-house speech recognition service: audio is not stored, clips up to 180 seconds.
  • A Telegram bot and MCP connection: tasks by voice in a messenger, or handed to an AI agent.
  • A Kotlin/Compose Android app that mirrors the web product pixel for pixel.
How it works

PHP 8.4 and Laravel 13, PostgreSQL, Redis for cache and queues, sessions in the database. The frontend is Vue 3 with Vue Router and Pinia, Vite, Tailwind CSS 4, as a SPA/PWA. Auth runs through Sanctum: cookie session in the browser, tokens in the app. Speech is recognised by an in-house faster-whisper service, text is parsed by DeepSeek. The API has an OpenAPI spec and MCP tools for AI agents.

Outcome

A working product in production (memo-flow.ru) and an Android app. 603 automated tests plus a linter in CI cover input parsing, recurrence, reminders and access rules.
