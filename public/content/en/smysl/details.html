An app that turns a thought — spoken or typed — into notes, tasks, subtasks, calendar events and reminders. A web version and an Android app; I build all of it.

The task

Ordinary task trackers ask you to fill in fields: project, due date, priority, assignee. A thought caught on the move therefore stays in your head or in an unstructured note — sorting it out later is separate work that usually never happens.

My role

Sole developer of the product: product logic, backend, web client, mobile app, speech recognition, integrations and deployment.

What I built
  • Voice or text input parsed automatically into entities: notes, tasks, subtasks, events, reminders.
  • Links between notes, tags and projects; participants and access levels from private to shared.
  • A calendar with month, week, day and list views; a task with a due date gets its event automatically.
  • Recurring tasks and reminders, plus a recycle bin with restore.
  • An in-house speech service on faster-whisper: audio is not stored, clips up to three minutes.
  • A Telegram bot and an MCP connection: dictate a task in a messenger or hand it to an AI agent.
  • A Kotlin/Compose Android app that mirrors the web product's design.
How it works

PHP 8.4 and Laravel 13, PostgreSQL, Redis for cache and queues, sessions in the database. Frontend: Vue 3 with Vue Router and Pinia, Vite, Tailwind CSS 4, as a SPA/PWA. Auth through Sanctum — cookie session in the browser, tokens in the app. Speech is recognised by an in-house service, text is parsed by DeepSeek. The API has an OpenAPI spec and MCP tools for AI agents.

Outcome

The product runs in production (memo-flow.ru) and as an Android app. 603 automated tests plus a linter in CI cover input parsing, recurrence, reminders and access rules — I run this product alone, and without tests that would be too expensive.
