Контур.Закупки — интеграция

Fullstack Laravel Livewire Битрикс24 API

Интеграция государственных закупок в Битрикс24: закупки приходят в портал вместе с файлами, статусы обновляются, нужные отбираются фильтрами и триггерами.

Задача

Менеджеры искали закупки на сайте и вручную переносили в портал: файлы терялись, статусы устаревали, а выигранные закупки находились не сразу.

Моя роль

Fullstack-разработчик: интеграция с «Контур.Закупками», выгрузка в Битрикс24, фильтры и триггеры.

Что сделал
  • Выгрузка государственных закупок из «Контур.Закупок» в Битрикс24 вместе со всеми файлами.
  • Отслеживание статусов закупок в портале.
  • Фильтры: только выигранные закупки, закупки с результатами или по заданным условиям.
  • Триггеры на конкретные закупки — чтобы нужная не прошла мимо.
Как устроено

Laravel и Livewire с интеграцией по API «Контур.Закупок» и REST API Битрикс24: данные и файлы переносятся в портал, статусы синхронизируются.

Результат

Закупки, файлы и статусы живут в портале: менеджер видит выигранные закупки и не собирает их вручную.
