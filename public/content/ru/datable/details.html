Datable

Laravel Vue.js PostgreSQL MySQL 6 месяцев

Платформа, которая собирает несколько баз данных в одном интерфейсе: структура, данные, аналитика и карта геоданных.

Проблема

Базы данных компании разбросаны по разным системам. Нужен один интерфейс, где видно структуру, можно смотреть данные, строить аналитику и отображать объекты на карте.

Моя роль

Руководитель проекта и backend-разработчик: архитектура, подключение внешних баз, права доступа, API.

Что сделано
  • Подключение к удалённым базам PostgreSQL и MySQL со сканированием структуры.
  • Просмотр и редактирование таблиц и полей, настройка типов полей.
  • Разграничение уровней доступа и ролей: владелец, редактор, читатель.
  • Публичный API с полной документацией для работы с данными баз.
  • Слой геоданных: объекты на карте и загрузка GeoJSON.
Как устроено

Backend на Laravel с Eloquent-моделями, авторизация по Bearer-токену (Sanctum). Структура удалённых баз синхронизируется в фоне через очереди. Frontend — Vue.js, карта — MapLibre.

Результат

Проект в работе: подключение к внешним базам, роли и уровни доступа уже работают на реальной базе института (83 таблицы, 668 полей).

Скриншоты
Ограничения

Интерфейс пока сырой: часть экранов сделана для проверки логики, а не для удобной работы.

Что улучшил бы сейчас
